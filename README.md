# 🔐 Crypto Tool (Encryption/Decryption CLI)

## 📌 Overview
A Python-based command-line tool that allows you to **encrypt and decrypt messages**.  
Includes both **modern encryption (Fernet - AES)** and **classic ciphers (Caesar & Vigenère)** for educational purposes.

## ✨ Features
- Generate and save Fernet keys.
- Encrypt/Decrypt messages securely using Fernet.
- Experiment with Caesar cipher.
- Experiment with Vigenère cipher.
- CLI-based, lightweight, easy to extend.
